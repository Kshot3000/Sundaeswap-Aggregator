# SundaeSwap DEX Aggregator

A lightweight DEX aggregator for Cardano that compares quotes across SundaeSwap, Minswap, and other AMMs to find the best price.

## Features
- Quote aggregation from multiple Cardano DEXs
- Best price routing simulation
- Fee estimation and slippage protection
- Simple CLI and web UI

## Usage
```bash
pip install -r requirements.txt
python aggregator.py --from ADA --to USDC --amount 1000
```

## Web UI
Open `index.html` in a browser for interactive quotes.
